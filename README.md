# 折页小册子拼版工具（社区印刷点）

一个供社区印刷点制作折页小册子的网页工具。上传**按阅读顺序排列**的多页 PDF，选择每帖 1 张纸（每帖 4 页）或 2 张纸（每帖 8 页），并可指定**章节起页**让章节首页落在右页；系统构造书序、按原页顺序分帖、仅在末帖补空白，生成 **A4 横向双面拼版 PDF**。每面左右各放一页并等比缩放，纸张短边翻转打印、折叠后页码连续。

页面会先展示**书序**（装订后的翻阅顺序，标明原页码、章节空白和末帖补白），再逐帖展示每张纸正反面的左右页码与空白位置，并支持一键下载结果。下载 PDF 与逐帖示意共用同一份“书序 → 原页”映射，原页内容不会遗漏或重复。

技术栈：Node.js + Express + pdf-lib + 原生 HTML/CSS/JavaScript，无前端构建步骤。

## 拼版规则

- 输出纸张：A4 **横向**（841.89 × 595.28 pt），每张纸正反两个面，每面左右并排放 2 个 A5 竖向页面，页面**等比缩放、居中**放置。
- 分帖：
  - **1 张纸/帖**：每帖 4 页（1 张纸对折）。
  - **2 张纸/帖**：每帖 8 页（2 张纸由外向内套叠后对折）。
  - 按原页顺序连续分帖；**只有末帖**补空白页凑满整帖（每帖页数必须是 4 的倍数）。
- 套帖页码（以每帖 8 页为例，第 1 张在外、第 2 张在内）：

  | 纸张 | 正面 左 / 右 | 反面 左 / 右 |
  |---|---|---|
  | 第 1 张 | 8 / 1 | 2 / 7 |
  | 第 2 张 | 6 / 3 | 4 / 5 |

  4 页/帖时仅取第 1 张：正 4/1，反 2/3。

- **章节起页（可选）**：用逗号分隔填写**原 PDF 页码**（1 起，中英文逗号均可，多余空格会忽略），指定各章节的起始页；**留空表示不指定**，结果与未启用该功能时一致。
  - 书序位置从 1 计，**奇数位置为右页、偶数位置为左页**。指定的章节起页必须落在右页：若它按原页顺序将落在偶数位置，则**在它前面插入一页“章节空白”**。
  - 后续判断计入此前插入的空白（位置顺延）；章节起页已在奇数位置时不插空。
  - 构造完书序后再按上面的 4 页/帖、8 页/帖规则分帖，凑整只在**末帖末尾补白**，章节空白与末帖补白在结果中分别标明。
  - 例：6 页 PDF 指定 `2,3`，书序为 **P1、章节空白、P2、章节空白、P3、P4、P5、P6**。
  - 页码必须是正整数且不超过原 PDF 页数；重复、非整数、越界（含 0、负数、空项）均会报错。

- 打印：A4、横向、**双面、短边翻转**。按文件页序整份打印，每帖的纸沿竖直中线对折后按帖序叠齐装订即可。

## 快速开始（单条命令完成依赖安装与启动）

只需一条命令（自动安装全部依赖并启动服务，无需其他初始化）：

```bash
npm install && npm start
```

需 Node.js ≥ 20。

使用 Docker 时同样是一条命令（自动构建镜像、安装依赖并后台启动）：

```bash
docker compose up --build -d
```

停止用 `docker compose down`。

## 访问地址与端口

启动后用浏览器访问：

```
http://localhost:3000
```

端口可通过环境变量 `PORT` 修改（如 `PORT=8080 npm start`；使用 Compose 时同时调整 `docker-compose.yml` 的端口映射）。

## 使用步骤

1. 用浏览器打开 **http://localhost:3000**，点击上传区选择按阅读顺序排列的 PDF（也支持拖拽）。
2. 选择**每帖 1 张纸**或**每帖 2 张纸**；如需章节首页居右，在**章节起页**里用逗号填写原 PDF 页码（如 `2,3`），留空则不指定。
3. 点击「开始拼版」，查看拼版统计、**书序**（原页 / 章节空白 / 末帖补白）与每帖各张纸正反面的页码/空白位置示意。
4. 点击「下载拼版 PDF」保存，交给打印设备双面打印（短边翻转）。

## 打印与装订提示

- 纸张 A4，方向横向；双面打印选择 **短边翻转**（部分驱动写作“沿短边装订/翻转短边”）。
- 每张纸先出正面（外页）、后出反面（内页），按文件页序打印即可，无需手动挑页。
- 2 张/帖时，第 1 张在外、第 2 张在内套叠，沿竖直中线对折。
- 各帖按帖序排好，在折缝处装订，页码自然连续。

## 接口说明

- `POST /api/impose`：`multipart/form-data`
  - `pdf`：原 PDF 文件（至少 2 页，默认 ≤ 100MB）。
  - `sheetsPerSignature`：`1`（每帖 4 页）或 `2`（每帖 8 页）。
  - `chapterStarts`：可选，逗号分隔的原 PDF 页码，如 `2,3`；留空或不传表示不指定。重复、非整数、越界返回 `400` 与中文错误信息。
- `GET /api/health`：返回 `{"ok":true}`，用于探活。

## 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` | `3000` | 服务监听端口 |
| `MAX_UPLOAD_MB` | `100` | 上传 PDF 大小上限（MB） |

## 说明

- 文件只在服务器内存中处理，不会写入磁盘；上传限制默认 100MB。
- 加密 PDF 使用 pdf-lib 的宽松模式加载；若 PDF 本身无法解析会返回明确错误提示。
